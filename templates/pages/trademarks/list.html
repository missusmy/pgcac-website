Trademarks

PostgreSQL Community Association (PGCA)

The PostgreSQL Community Association of Canada (PGCA) holds the trademarks for the PostgreSQL project on behalf of the PostgreSQL Global Development Group and the PostgreSQL Core Team. This page provides information about the trademarks held by PGCA and how they can be used.

PGCA-held trademarks

The PostgreSQL Community Association holds the following trademarks on behalf of the PostgreSQL project:

  • PostgreSQL (Canada, EU, US)
  • Postgres (EU, US)
  • Slonik Elephant Image (EU, US)

These trademarks can be used according to the PostgreSQL Trademark Policy.
